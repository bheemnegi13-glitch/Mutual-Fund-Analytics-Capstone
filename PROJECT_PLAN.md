# Project Plan

1. Inspect all 10 datasets and validate columns, row counts, missing values and duplicates.
2. Clean and transform dates, categories and numeric fields with Pandas.
3. Analyze scheme returns, risk metrics, expenses and benchmark-relative performance.
4. Analyze investor transactions by type, state, age group, gender and payment mode.
5. Analyze SIP inflows, category inflows, AUM and folio growth.
6. Analyze portfolio holdings by sector and scheme.
7. Build SQL tables and business questions.
8. Create a Power BI dashboard.
9. Prepare findings, limitations and final report.
